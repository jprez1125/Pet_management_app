Project Overview
The Pet Management System will allow users to:
- Create and manage pet profiles
- Track appointments and medical information
- View and update pet details
- Support future expansion for owners, staff, and scheduling features

Features
- User authentication
- Add/Edit/Delete pets
- Track medications
- Schedule appointments
- View medical notes
- Clean, responsive UI

Tech stack

Django
HTML/ CSS
